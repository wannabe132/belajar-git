BELAJAR CSS

CSS (Cascading Style Sheets) adalah bahasa yang digunakan untuk mengatur tampilan dan desain sebuah halaman web. Dengan CSS, kita dapat mengubah warna, ukuran dan jenis tulisan, jarak, posisi, ukuran elemen, serta tata letak halaman agar terlihat lebih menarik dan terstruktur. CSS biasanya digunakan bersama HTML, di mana HTML berfungsi untuk membuat struktur halaman, sedangkan CSS digunakan untuk mengatur tampilannya. Dengan menggunakan CSS, sebuah website dapat dibuat lebih rapi, nyaman dilihat, dan responsif pada berbagai ukuran perangkat seperti komputer, tablet, maupun smartphone.
